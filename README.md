# Simulation Modelling

This repository contains Jupyter Notebook(s) for simulation modelling.

## Contents

- `*.ipynb` — notebooks with code, notes, and results.

## Getting started

1. Clone the repository:
   ```bash
   git clone https://github.com/AmirBR996/simulation_modelling.git
   cd simulation_modelling
   ```

2. Create and activate a Python environment (recommended):
   ```bash
   python -m venv .venv
   # Windows
   .venv\Scripts\activate
   # macOS/Linux
   source .venv/bin/activate
   ```

3. Install dependencies.

   If you have a `requirements.txt` file, run:
   ```bash
   pip install -r requirements.txt
   ```

   Otherwise, install what the notebooks require (common starting point):
   ```bash
   pip install jupyter numpy pandas matplotlib
   ```

4. Launch Jupyter:
   ```bash
   jupyter lab
   ```
